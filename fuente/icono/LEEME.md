# Icono de la pestaña

`icono.png` es el dibujito que aparece en la pestaña del navegador junto a
"Artemisa" (y como icono si alguien guarda el sitio en la pantalla de inicio de
su celular). Ahora es la "A" del logo, negra sobre un círculo crema.

Para cambiarlo, sube otra imagen **con el mismo nombre**, `icono.png`:

- **Cuadrada**, de preferencia 512 × 512 px o más.
- Si es redonda, con las esquinas **transparentes**.
- Algo simple: en la pestaña se ve de 16 px, así que los detalles finos o las
  palabras no se alcanzan a ver.
- **Renombra la imagen en tu computadora antes de subirla.** Renombrar una
  imagen en el editor de GitHub la deja vacía.

`logo-original.png` es el logo completo del que se recortó la "A"; solo se
guarda como referencia.

El sitio se reconstruye solo. El navegador a veces guarda el icono anterior:
si no ves el cambio, recarga la página con Ctrl + F5.
